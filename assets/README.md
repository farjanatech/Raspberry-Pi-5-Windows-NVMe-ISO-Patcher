# Application icon

`pi5-nvme.png` is the exact 1254 x 1254 PNG supplied by the repository owner as `icon.png` on 2026-10-15. Its original pixels, palette and transparency are preserved; no new artwork was generated and no image editing was applied.

The same file supplies the application/window icon, the GUI header, the application-menu entry and the desktop shortcut. Qt and the desktop scale it for their display sizes. The filename stays stable for installer and uninstaller compatibility, while each installed version has its own snapshot path.
