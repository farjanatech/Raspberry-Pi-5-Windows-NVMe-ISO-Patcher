# Desktop branding

`pi5-nvme.png` is a 64 × 64 desktop-size derivative of the image supplied by the repository owner in the project conversation. It is used for the window icon, sidebar, application-menu entry and desktop shortcut. No new logo was generated. Resizing and palette reduction were used for a compact desktop asset.
